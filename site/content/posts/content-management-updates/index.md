## Progress Report
![020](/assets/portfolio/020/1200.jpg)
I recently posted about *Basalt*, the engine on which this website now runs. The system has been refined slightly and smoke tested -- because it's now live on the base domain as well. 

The project was built out exclusively for this photography website, but I realized it could scale in a small way to manage the entire website for the way I'd like.

Features are minimal and additions incremental, but it's now workable in a meaningful way: 
- Basalt instances deployed to a website can be condifugred namely between a photos website like this, or a personal website like https://ctsmith.org, still complete with Hugo's blog posting functionality. 

I've even baked in functionality for a Blog-centered website. 

Give Basalt a whirl. https://github.com/adobebulk/basalt
